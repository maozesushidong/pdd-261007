# 运营看板

看板参考 `https://work.iiting.fun/pdd/v1/` 的信息层级，但数据来自本系统 API，不复制外部页面数据。

页面包括时间和店铺筛选、八项汇总指标、场景分布、自动化占比、店铺健康度、工单明细、详情抽屉、阶段时间线、实时日志、证据、前端转人工、机器人转人工和验证定位。所有数据来自 `/api/v1`，SSE 用于刷新提示，前端不直连 PostgreSQL。

默认访问者为内部只读角色。唯一 `system-owner` 通过 Cookie Session 和 CSRF 保护的 API 执行分类修订、数据修订、转人工处理和流程控制。工单分类为 `automated | manual`，会影响看板指标和 CSV；分类修改不会直接触发 PDD/TMS 操作。原始 `workflow_events` 和审计日志不可修改，修订内容保存在版本化历史和 `payload.manualOverrides`。

日志中心可按店铺、系统、阶段、严重级别和原因筛选。工单详情展示 PDD/OMS/TMS、物流、证据、事件和修订历史，所有写操作记录操作者、原因和版本。

验证定位显示当前店铺、系统、阶段、URL、元素坐标、诊断截图和置信度。它只帮助人工找到滑块或验证码，不执行拖动、识别或绕过。
