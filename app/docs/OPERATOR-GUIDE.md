# 拼多多工单系统零基础操作手册

## 每天怎么启动

1. 打开项目文件夹 `C:\Users\Administrator\Desktop\pdd-0731`。
2. 双击 `START-PDD.cmd`。
3. 等待 Docker Desktop 和管理台自动打开。
4. 管理台地址是 <http://127.0.0.1:4173>。
5. `START-PDD.cmd` 会自动启动 Windows 原生验证码提醒器；浏览器右上角铃铛只是备用提醒。

不要重复双击启动文件。已经启动时再次双击不会删除数据，但没有必要。

## 系统处理哪些工单

1. 在途无理由退款处理
2. 已发货无轨迹退款
3. 异常网点预警
4. 消费者担忧货物无法送达
5. 物流异常主动服务
6. 逆向物流已签收退款
7. 消费者申请退款后提示拦截
8. 好人好事服务单-加急发货
9. 消费者反馈未收到货
10. 消费者拒收问题处理
11. 退货退款

## 收到验证码提醒怎么办

1. 点击桌面通知，或点击管理台右下角红色提醒。
2. 点击“打开远程窗口”。
3. 在拼多多页面完成滑块、验证码或扫码登录。
4. 如果完成验证后程序没有继续，可在 VNC 内的拼多多业务页按一次 F5 或 Ctrl+R；不要刷新外层 noVNC 页面。
5. 当前状态为 `waiting-human` 时，程序会检测拼多多主页面刷新并自动复检；验证码消失后继续同一订单，验证码仍在则保持等待。
6. 不要重复点击查询、提交，也不要连续刷新。

Windows 原生提醒器不依赖浏览器通知权限。即使管理台被最小化或浏览器已经关闭，只要系统是通过 `START-PDD.cmd` 启动的，验证码出现时仍会弹出置顶窗口并播放系统提示音。关闭提醒后，如果验证码还没有解决，约 1 分钟后会再次弹出。

首次运行 `START-PDD.cmd` 后，系统还会安装当前 Windows 用户的登录自启动任务。提醒器会在登录 Windows 时启动；如果 Docker 还没有启动，它会安静等待 API 可用。

店铺浏览器入口以管理台当前显示为准。当前本机原生模式直接使用每家店铺的独立浏览器窗口；部署 noVNC 时，由动态店铺 ID 生成对应入口，不再把三家店铺和 `6080-6082` 端口写死。前端新增店铺后，应出现新的独立 Profile 和浏览器入口。

浏览器子进程启动或恢复时，VNC 桌面保持连接并显示“浏览器正在启动或恢复”提示，不再显示黑屏；VNC 服务短暂重启时 noVNC 会每 1 秒自动重连。

## 页面显示“操作频繁”怎么办

不要继续点击，也不要重启 Worker。程序会先等待 3 分钟；如果平台仍有限制，会逐步延长等待时间，单次最多等待 30 分钟。平台恢复后程序自动继续。

## 页面显示“等待物流更新”怎么办

不要操作。当前工单已经释放，不会占住店铺。到达页面显示的时间后，系统会自动重新查询物流，并且可以处理其他新工单。

## 页面显示“等待人工复核”怎么办

1. 打开管理台的“转人工”。
2. 阅读人工复核原因和证据。
3. 只有确认业务结果时才操作。
4. 不知道应该选什么时不要猜，交给业务负责人决定。

## 什么时候找技术人员

- 管理台和所有已启用店铺浏览器都打不开。
- 同一个状态超过 30 分钟没有更新时间，而且不是“平台限流”或“等待物流”。
- 拼多多提示账号被冻结、限制或需要申诉。
- 页面要求决定退款、拦截或快递结果，但业务人员不能确认。

不要删除 Docker 数据卷，不要清空 PostgreSQL、Redis、MinIO，也不要反复重启同一个 Worker。
