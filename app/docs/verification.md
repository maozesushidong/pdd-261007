# 验证定位

Worker 检测可见的验证码、滑块、验证输入框和 iframe，保存店铺、系统、阶段、元素矩形、frame URL、页面 URL、置信度和诊断截图。截图以 SHA-256 对账后进入 MinIO，数据库只保存对象 Key 和元数据。

前端显示截图红框。操作员通过对应 Windows 浏览器或 noVNC 完成验证；有界面 Worker 会持续检测验证是否消失并从原阶段继续。“人工完成后复检”只创建 `verification-recheck` 指令，不能直接把验证记录伪造为已解决。旧定位记录标为 `expired`，保留用于审计。

不实现验证码识别、滑块自动拖动或任何平台验证绕过。
